Privacy policy

For "Studio uploads", the tool used by The Calm Grower. Last updated 17 November 2026.

What the app is

Studio uploads is a private tool run by the owner of The Calm Grower on their own computer. It uses YouTube API Services to upload the channel's own videos, thumbnails and captions to the owner's own YouTube channel, and to set their titles, descriptions and publishing schedule. It is not offered to the public.

YouTube API Services

This app uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data the app accesses

  • Access to upload and manage videos on the authorised YouTube channel, granted through Google sign-in.
  • Basic channel details returned by the API (channel ID and name) to confirm the right channel is used.

The app does not access viewers' personal data, and it does not read email, contacts or any other Google account data.

How data is used and stored

The sign-in token is stored only on the owner's own computer, so videos can be uploaded after the owner approves them. Nothing is sold, shared with third parties, or used for advertising. Video files and their details are the channel's own content.

How to remove access

Access can be removed at any time in your Google Account's third-party access settings. Removing it stops all uploads. Deleting the token file from the computer also removes the stored data.

Contact

Questions about this policy: contact The Calm Grower through the channel's YouTube page, youtube.com/@TheCalmGrower.
